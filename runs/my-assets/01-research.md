## 레퍼런스
### R1 · 퍼그샵 — 미션 현황 (단계별 상태 배지)
- url: https://uibowl.io/name/%ED%8D%BC%EA%B7%B8%EC%83%B5?patterns=%EC%9D%B8%EC%A6%9D%ED%95%98%EA%B8%B0&imgId=cmq7f10kf00g5l404v8lob82e
- 관찰: 항목마다 한 줄 행으로 나열하고 오른쪽 끝에 "완료", "검수중", "대기" 같은 작은 상태 배지와 화살표(>)를 둔다. 상태별로 배지 색을 달리해서 진행 중인 항목이 바로 눈에 띄고, 행 아래에 보조 문구(예: 지금 수행 가능한 미션)로 다음 행동을 알려 준다.

### R2 · 셀레트립 — 여행 설정 (공개 범위 행)
- url: https://uibowl.io/name/%EC%85%80%EB%A0%88%ED%8A%B8%EB%A6%BD?patterns=%EC%84%A4%EC%A0%95&imgId=cmqp088u8000hl504m30sar67
- 관찰: 이름·날짜·목적지·공개 범위를 라벨(작은 회색) + 현재 값(굵은 검정) 두 줄 행으로 쌓고, 행 사이는 얇은 구분선만 쓴다. "공개 범위 / 비공개"처럼 현재 선택값을 그대로 노출하고, 행을 누르면 선택 화면으로 넘어간다. 삭제는 맨 아래 텍스트 링크로 약하게 둔다.

### R3 · 수현이랑 — 공유 앨범 업로드 (등록 폼)
- url: https://uibowl.io/name/%EC%88%98%ED%98%84%EC%9D%B4%EB%9E%91?patterns=%EC%83%9D%EC%84%B1%ED%95%98%EA%B8%B0&patternName=%EA%B3%B5%EC%9C%A0%20%EC%95%A8%EB%B2%94%20%EC%97%85%EB%A1%9C%EB%93%9C
- 관찰: 분류를 필(pill) 형태 칩으로 한 번에 고르게 하고, 선택된 칩만 테두리·글자색을 강조한다. 제목(13/30), 설명 (선택)(15/200)처럼 글자 수 카운터를 입력칸 오른쪽 아래에 두고, 필수/선택 여부를 라벨에 적는다. 하단에 폭 전체를 쓰는 둥근 "완료" 버튼이 고정되어 있다.

### R4 · 이지태스크 — 업무 맡기기 (임시저장 불러오기)
- url: https://uibowl.io/name/%EC%9D%B4%EC%A7%80%ED%83%9C%EC%8A%A4%ED%81%AC?patterns=%EC%83%9D%EC%84%B1%ED%95%98%EA%B8%B0&imgId=cm8piilwx002rjl0dgncrkndt
- 관찰: 바텀시트 안에 "이전 요청서 / 임시저장" 탭을 두고 탭 이름 옆에 개수 배지(1, 2)를 붙인다. 각 항목은 카테고리 경로 · 제목 · "임시저장 일시"를 세 줄로 보여 주고, 제목이 비어 있으면 회색 안내 문구로 대신 표시한다.

### R5 · 달다방 — 글쓰기 (첨부 + 임시저장/저장 버튼)
- url: https://uibowl.io/name/%EB%8B%AC%EB%8B%A4%EB%B0%A9?patterns=%EA%B8%80%EC%93%B0%EA%B8%B0&imgId=cmuc8yeq3000ek004slr9iegn
- 관찰: 본문 입력 아래에 "대표 이미지 추가 +", "이미지 추가 +" 같은 첨부 행을 아이콘과 함께 나열한다. 하단에 "임시저장"(흰 배경 외곽선)과 "저장"(채움) 두 버튼을 나란히 두어 주/보조 행동을 구분한다.

## 반영할 점
- [R1] 내 자산 목록의 각 행 오른쪽에 심사 상태 배지(임시저장 · 검수 대기 · 수정 요청 · 승인됨 · 반려)를 붙이고, 액센트는 사용자가 행동해야 하는 "수정 요청"에만 써서 모노크롬 안에서 우선순위를 드러낸다.
- [R1, R4] 행 아래 보조 문구로 다음 행동을 안내한다(예: 수정 요청 → "운영자 요청을 확인하고 다시 제출하세요", 임시저장 → 마지막 저장 일시).
- [R2] 자산 행에 공개 범위(비공개 · 멤버 공개 · 판매 신청)를 라벨 + 현재 값 형태로 함께 노출해, 목록에서 바로 누가 볼 수 있는지 알 수 있게 한다. 기본값은 비공개로 둔다.
- [R3] 새 자산 등록 폼에서 자산 종류(프롬프트 · 스킬 파일 · 자동화 템플릿 · 사용 사례)와 공개 범위를 필 칩으로 고르게 한다. "판매 신청" 칩은 판매 승인 회원이 아니면 비활성 처리하고 이유를 한 줄로 알려 준다.
- [R3] 제목·설명 입력칸에 글자 수 카운터와 필수/선택 표기를 둔다.
- [R5] 파일 첨부를 "+" 아이콘이 달린 행으로 만들고, 첨부된 파일은 같은 영역에 파일명 행으로 쌓는다.
- [R3, R5] 등록 폼 하단에 "임시저장"(외곽선)과 "등록"(액센트 채움) 두 버튼을 고정해, 임시저장은 draft로 남고 판매 신청을 고른 경우에만 등록 시 검수 대기로 넘어가게 한다.
- [R4] 목록 상단에 상태 필터 탭(전체 · 임시저장 · 검수 중 · 완료)을 두고 탭마다 개수 배지를 붙인다.
- [R2, R4] 자산이 하나도 없을 때는 빈 목록 대신 "첫 자산을 등록해 보세요" 안내와 등록 버튼을 보여 준다.
