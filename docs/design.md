# Design Guide (디자인 가이드)

## 1. 디자인 방향
- 분위기 / 키워드: (예: 깔끔한, 따뜻한, 미니멀)
- 참고 서비스:

## 2. 색상
| 역할 | 색상 | 용도 |
|---|---|---|
| Primary | #2563EB | 주요 버튼, 강조 |
| Background | #FFFFFF | 페이지 배경 |
| Surface | #F5F5F7 | 카드 배경 |
| Text | #111111 | 본문 글자 |
| Text Sub | #6B7280 | 보조 글자 |
| Error | #DC2626 | 오류 표시 |

## 3. 타이포그래피
- 폰트: Pretendard
- 제목 (H1): 28px / Bold
- 소제목 (H2): 20px / SemiBold
- 본문: 16px / Regular
- 캡션: 13px / Regular

## 4. 간격 & 모서리
- 간격 단위: 4px 배수 (4, 8, 12, 16, 24, 32)
- 모서리 둥글기: 버튼 8px, 카드 12px

## 5. 컴포넌트 규칙
- 버튼: Primary 색 배경 + 흰 글자, 높이 48px
- 카드: Surface 배경, 패딩 16px, 그림자 없음
- 입력창: 테두리 1px #E5E7EB, 포커스 시 Primary 색

## 6. 규칙 (AI가 지켜야 할 것)
- 위에 정의한 색상/폰트/간격만 사용한다.
- 새 컴포넌트를 만들 때는 이 문서를 먼저 확인한다.
