# Design Guide (디자인 가이드)

> 사람이 읽는 설명서다. **기준 값은 `rules/rules.json`** 이고, 둘이 다르면 rules.json이 이긴다.
> 근거: PRD 14 — 모노크롬 캔버스 + 단일 액센트, 그림자 없는 깊이 표현, 필(pill) 형태 인터랙션.

## 1. 디자인 방향
- 키워드: 실험실, 자산 라이브러리, 모노크롬, 단일 액센트
- 자료실처럼 나열하지 않고, 상태(무료/유료/판매 신청/검수)를 라벨로 분명히 보여준다.

## 2. 색상
| 역할 | 색상 | 용도 |
|---|---|---|
| Text | #0A0A0A | 본문, 제목 |
| Strong | #3D3D3D | 진한 보조 요소, 아이콘 |
| Sub | #8A8A8A | 보조 글자, 비활성 |
| Line | #E5E5E5 | 구분선, 카드 테두리 |
| Surface | #F5F5F5 | 카드·섹션 면 |
| Background | #FFFFFF | 페이지 배경 |
| **Accent** | #D4FF3A | 단 하나의 강조색. 주요 CTA, 선택 상태 |

- 액센트 위 글자는 #0A0A0A만 쓴다.
- 에러·경고용 색은 따로 없다. 반려/수정 요청 같은 상태는 **글자 라벨 + 아이콘**으로 구분한다.

## 3. 타이포그래피
- 폰트: Pretendard 1종
- 크기: 28 (H1) / 20 (H2) / 16 (본문) / 14 (보조) / 12 (캡션) px

## 4. 간격 & 모서리
- 간격: 4의 배수만 (0~48px)
- 모서리: 0 / 12 / 999(pill)만 허용
  - 버튼·칩·탭·필터: 999 (pill)
  - 카드·시트: 12
  - 구분 영역: 0

## 5. 깊이
- `box-shadow` 사용 금지
- 깊이는 선(#E5E5E5)과 면 색(#F5F5F5 / #FFFFFF) 차이로만 표현한다.

## 6. 화면
- 뷰포트 390 × 844

## 7. Do / Don't
| Do | Don't |
|---|---|
| 액센트는 화면당 주요 CTA·선택 상태에만 | 액센트 외 다른 색 추가 |
| 버튼·칩은 pill | 버튼 모서리 8px 같은 중간값 |
| 선·면으로 영역 구분 | 그림자 |
| 상태는 PRD 상태 값 라벨로 표기 | MVP 범위 밖 기능(허들링 픽, 구매, 결제, 정산, 피드백 등) 노출 |
