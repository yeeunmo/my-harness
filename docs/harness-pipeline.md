# 하네스 파이프라인 (harness-pipeline)

## 단계
| # | 단계 | 입력 | 출력 | story-work |
|---|---|---|---|---|
| 1 | 리서치 | 화면 이름, prd.md | 레퍼런스 3~5개 + 반영할 점 (항목마다 uibowl 출처 URL) | ①② |
| 2 | 설계 | 1의 출력, prd.md, story-service.md | 화면 설계서 (섹션, 기능, 데이터 필드, PRD 근거 번호) | ③ |
| 3 | 제작 | 2의 출력, design.md | 390×844 HTML 1안 | ④⑥ |
| 4 | 판정 | 3의 출력 + 1·2의 출력, design.md, prd.md | 조건별 통과/실패, 위반 목록 → 전부 통과 시 사람 승인 | ⑦⑤ |

- 흐름: 1 → 2 → 3 → 4 (한 방향)
- 시안: 매번 1안만 만든다 (story-work ④의 2~3안 비교는 하지 않음)
- 리서치: uibowl 검색을 자동으로 사용, 화면당 레퍼런스 3~5개

## 되돌아가는 지점
| 실패 조건 | 되돌아가는 단계 |
|---|---|
| D2 크기, D3 design.md 밖 값 | 3 제작 |
| D4 범위 밖 단어, 권한·상태 위반 | 2 설계 |
| D5 출처 없는 레퍼런스 | 1 리서치 |
| 같은 단계로 3번 되돌아감 | 멈추고 사람에게 알림 |

- 되돌아간 단계 이후는 모두 다시 실행한다 (예: 2로 가면 2 → 3 → 4).
